# Coffee Five — nova proposta de site

Projeto estático preparado para GitHub Pages, com duas rotas:

- `/` — página institucional da Coffee Five
- `/cardapio/` — cardápio completo, com filtros e busca

O site não requer instalação nem build. Para publicar, basta ativar o GitHub Pages a partir da branch `main` e da pasta raiz do repositório.

As fotos e as informações apresentadas foram preservadas a partir do site público atual da Coffee Five. A versão organiza o conteúdo para a navegação ficar mais direta, especialmente no cardápio.
